# SakikoGames · 雨夜闪避

独立全屏网页小游戏。帮助祥子在狭小的出租屋里躲开扔来的酒瓶。与 SakikoPet 的运行、存档和经济系统没有连接，不读取桌宠数据，也没有联网服务或账号。

## 在线游玩

https://Obliv1onis.github.io/SakikoGames/

## 本地运行

需要 Node.js 18 或以上，无需安装依赖：

```sh
npm start
```

浏览器打开 http://127.0.0.1:4178 。页面占满浏览器，点击右上角全屏按钮进入浏览器全屏。浏览器限制网页必须通过用户点击才能进入全屏。

- A / D 或 ← / →：移动。
- Space / W / ↑：跳跃。
- Shift：短冲刺，期间可穿过酒瓶，冷却约 1.65 秒。
- Escape / P：暂停或继续。切到其他窗口／后台自动暂停。
- 手机、平板有屏幕按钮。
- 三颗心；每 20 秒提升一波难度，预警后才出瓶；近距离闪避加分。
- 默认静音，右上角可开启合成音效。当前没有环境雨声音轨。
- 只有最佳分数保存在浏览器 localStorage；禁用本地存储时仍能游玩。

## 素材与边界

- `assets/apartment.png` 为内置 image_gen 新生成的出租屋夜景概念背景，不声称逐帧复原动画里的实际房间。
- 祥子图片取自本机 SakikoPet 项目已有角色素材，保留原画，不重新绘制人物。相关角色与原始素材权利属于原权利人，本项目不另行授予分发授权。
- 父亲采用场景内简单的绘制剪影，酒瓶、预警和碎片由 Canvas 绘制；没有伤口或血腥画面。
- 独立发布至 SakikoGames 仓库及 GitHub Pages，不提交到 SakikoPet 仓库。真机触屏和各浏览器支持需分别验收。

## 已完成验证

Node 逻辑回归、脚本语法检查，以及 Chrome 的开始／结算／全屏开关已验证。真机触屏和 Safari 兼容性尚未验收；场景为同人游戏概念背景，不声称精确复刻动画原场景。

## 投掷变化

十种投掷组合通过随机洗牌抽取：直投、高抛、滚地、连投、反弹、散射、横扫、双高抛、交错和先慢后快。落点在预警时锁定，不显示攻击名称。滚地瓶可跳过，反弹瓶第一次落地后仍有危险。

开局约 22–30 秒后进入一次无文字提示的高密度攻击，持续 7–10 秒；结束后有 3 秒恢复时间，再经过随机间隔重新出现。高密度期间攻击更快、组合重叠，但仍保留预警、冲刺无敌和受击保护，限制场内投射物数量。
